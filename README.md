# game-nome

Brincadeiras educativas para a Julia, uma criança pequena que ainda não lê. Ela toca na tela, a voz do navegador fala em português, e os jogos ensinam letras, palavras e nomes de bichos.

Feito para celular e tablet (em pé e deitado), só com toque e voz.

## Jogos

- 👨‍👩‍👧 **Família**: soletrar Papai, Mamãe e Julia, protegendo cada letra dos bichos.
- 🚲 **Palavras**: soletrar palavras com figuras que se mexem.
- 🐾 **Encontre os animais**: a voz pede um bicho e ela pega no pasto.
- 🏁 **Corrida dos animais**: cada toque acelera o bicho na corrida.
- 🐷 **Três porquinhos**: construir as casas e fugir do lobo.
- 🍎 **Monstrinho comilão**: derrubar maçãs e uvas para o monstrinho comer.

## Como rodar

```
npm install
npm run dev
```

Feito com Next.js e React, sem backend: tudo roda no navegador.
